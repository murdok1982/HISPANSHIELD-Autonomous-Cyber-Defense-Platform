# INDEPENDENT ASSURANCE REVIEW — 0.1.3

> **Independence caveat:** this review was performed by the same engineering
> session that implemented the changes. It is adversarial in method but **not an
> external audit**. A pilot must commission an external reviewer with access to
> source, infrastructure and logs.

## 1. Checks performed

- Re-ran the full backend suite (669), edge (92), frontend (36), typecheck,
  build, ruff, format, mypy, bandit, pip-audit, gitleaks and npm audit.
- Re-executed Playwright on a **fresh** database, not reusing prior evidence:
  10 core + responsive + axe.
- Executed migrations `upgrade → downgrade base → upgrade`.
- Executed backup → restore into an isolated DB → counts → audit chain → API
  smoke test.
- Compared documentation claims with executable evidence; removed the E2E
  contradiction and stale endpoint tables.

## 2. Findings about the evidence itself

| Check | Result |
| :--- | :--- |
| Tests disabled/skipped silently? | No `skip` added; full suite runs. |
| Assertions weakened to pass? | Only two pre-existing zone tests were updated to send the newly mandatory `required_sl`; no assertion was relaxed. |
| Mocks hiding failures? | New importers/export/soft-delete tests use the real DB and HTTP client. |
| Documentation ahead of code? | Fixed: API reference now lists real routes; counts regenerated by scripts. |
| Old evidence reused? | No: E2E, backup/restore and scans were executed in this wave. |
| Claimed but unexecuted? | Explicitly marked NOT RUN: Docker/K8s runtime, Firefox/WebKit, 5k/100k, air-gap, external review. |

## 3. Residual risks accepted for a pilot

1. Internal-only security review and no third-party pentest.
2. No real container/orchestrator rollout.
3. No scale benchmark; FTS/partitioning incomplete.
4. Cloud/CSPM, legal hold, A4, durable agent runs, NIS2 tracker, ETSI/CPE open.
5. Audit HMAC key and database in the same trust domain unless checkpoints are
   exported externally.
6. Outbox is at-least-once for external side effects; handlers must be
   idempotent.
7. Chromium-only accessibility/responsive evidence.

## 4. Verdict

**PILOT READY** — functional, security-hardened for the audited scope, with
reproducible E2E, backup/restore and migration evidence. **Not PRODUCTION
READY** until the residuals above are closed and an external review is
completed.
